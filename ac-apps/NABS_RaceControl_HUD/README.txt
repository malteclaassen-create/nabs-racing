NABS Race Control
=================

DEUTSCH

Was ist das?
Eine App fuer Race Control. Bei Kontakten, Massenunfaellen, Drehern, Off-Tracks
und gestoppten Autos gehen Kamerafenster fuer das Auto auf.

Installieren
1. Den Ordner "NABS_RaceControl_HUD" nach
   ...\steamapps\common\assettocorsa\apps\lua\ kopieren.
2. AC starten, in der App-Leiste "NABS Race Control" einschalten.
   Braucht Custom Shaders Patch.

Einrichten
1. Auf nabsracing.com einloggen, Admin > Race control, dort steht dein Code.
   (Die Rolle Race control vergibt ein Admin.)
2. In der App, Reiter Live, den Code eintragen. Oben steht dann gruen
   "Website: Connected". Der Code bleibt gespeichert.
3. Auf den Server gehen. Fertig.

Reiter
Live      Code, Verbindung, und alles was gerade passiert. Mit "Show" holst du
          jede Karte von Hand auf den Bildschirm.
Pop-ups   Was von selbst aufgeht, wie lange die Karten bleiben, Ton und
          Lautstaerke.
Cameras   Welche Blickwinkel, wie viele Karten, Groesse, Position.
Picture   Helligkeit und Qualitaet.

Kontakte und Off-Tracks kommen ueber die Webseite vom Server, Dreher und
gestoppte Autos erkennt die App selbst. Ohne Code gibt es nur die zwei.
Den Code nicht weitergeben. Wenn er rausgegangen ist: auf der Webseite
"New code" druecken.


ENGLISH

What is it?
An app for race control. Contacts, pile-ups, spins, off tracks and stopped
cars open camera cards for that car.

Install
1. Copy the folder "NABS_RaceControl_HUD" into
   ...\steamapps\common\assettocorsa\apps\lua\
2. Start AC and switch on "NABS Race Control" in the app bar.
   Needs Custom Shaders Patch.

Set up
1. Log in on nabsracing.com, Admin > Race control shows your code.
   (An admin gives you the race control role.)
2. In the app, Live tab, type the code. The top line turns green:
   "Website: Connected". The code is kept.
3. Join the server. Done.

Tabs
Live      Code, connection, and everything happening right now. "Show" puts
          any card on screen by hand.
Pop-ups   What opens by itself, how long cards stay, sound and volume.
Cameras   Which views, how many cards, size, position.
Picture   Brightness and quality.

Contacts and off tracks come from the server through the website, spins and
stopped cars are spotted by the app itself. Without a code you only get those
two. Keep your code to yourself. If it got out, press "New code" on the site.
