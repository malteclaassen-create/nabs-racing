# 3D replay car

Source: [Kenney Racing Kit 2.0](https://kenney.nl/assets/racing-kit), `raceCarRed.glb`,
saved here as `raceCar.glb`. Author: Kenney. License: CC0 1.0; original notice in
`License.txt`. Downloaded 2026-10-13 from the author's Racing Kit archive.

The file is unchanged. The 3D replay (`src/utils/lapViewer3d.js`) scales it to a
2010 Formula 1 car (the league's `formula_2010`), keeping the wheels round, and
draws the material named `red` in the lap's colour. A generic formula car, not a
replica of any team's car.

The 2D map still draws the Car Kit car from `../kenney-race`.
